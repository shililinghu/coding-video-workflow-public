# coding-video-workflow-public

Reusable video preparation and rendering scripts.

This public edition contains reusable source only, with independent Git history. Read [PRIVACY.md](PRIVACY.md) before configuring it.

Original runtime configuration, personal data and media are intentionally absent. Install dependencies listed by the included package or requirements files and supply your own local settings. Examples are fictional.

## Usage

Work in `workflow/`. The included scripts are reusable rendering components from a source snapshot. They expect project specific narration, scene data and rendering inputs supplied by the user; the original production workspace and media are excluded. They are not a complete ready to render project.
